# 📂 Smart File Organizer

A modern desktop application built with **Python** and **CustomTkinter** that automatically organizes files into categorized folders. It helps keep folders clean by sorting files based on their extensions, handling duplicate filenames, and generating an activity log.

---

## ✨ Features

- 📂 Organize files automatically by type
- 🖼️ Image file organization
- 🎥 Video file organization
- 🎵 Audio file organization
- 📄 Document file organization
- 🗜️ Archive file organization
- 💻 Source code file organization
- 📁 Automatically creates folders if they don't exist
- 🔄 Prevents duplicate filenames automatically
- 📊 Displays organization summary
- 📝 Generates an activity log (`organizer_log.txt`)
- 🎨 Modern GUI built with CustomTkinter
- ⚡ Fast and easy to use

---

## 📂 Supported File Types

| Category | Extensions |
|----------|------------|
| Images | .jpg .jpeg .png .gif .bmp .webp |
| Videos | .mp4 .mkv .avi .mov .wmv |
| Audio | .mp3 .wav .aac .flac |
| Documents | .pdf .doc .docx .ppt .pptx .xls .xlsx .txt .csv |
| Archives | .zip .rar .7z |
| Code | .py .cpp .c .java .html .css .js |
| Others | Any unsupported file type |

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Navdeepkaur26/Smart-File-Organizer.git
```

### Open Project

```bash
cd Smart-File-Organizer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
python main.py
```
