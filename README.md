# 📂 Smart File Organizer

A Python project that automatically organizes files into different folders based on their file type.

## ✨ Features

- 🖼️ Organizes Images
- 📄 Organizes PDFs
- 🎥 Organizes Videos
- 🎵 Organizes Audio Files
- 📁 Organizes Documents
- 📦 Moves Other Files Automatically

## 🛠️ Technologies Used

- Python
- OS Module
- Shutil
- Tkinter

## 🚀 How to Run

```bash
python main.py
```

## 📂 Output

The program creates folders like:

- Images
- PDFs
- Videos
- Audio
- Documents
- Others

and moves files automatically.
