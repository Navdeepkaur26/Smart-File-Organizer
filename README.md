# 📂 Smart File Organizer

A simple Python application that automatically organizes files into separate folders based on their file extensions, making your workspace clean and well-organized.

## ✨ Features

- 📁 Automatically sorts files into folders
- 🖼️ Organizes image files
- 📄 Organizes PDF files
- 🎥 Organizes video files
- 🎵 Organizes audio files
- 📝 Organizes document files
- 📦 Stores unsupported file types in an **Others** folder
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

- Python
- os Module
- shutil Module
- Tkinter (GUI)

## 📁 Folder Structure

```
Smart-File-Organizer/

```

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/USERNAME/Smart-File-Organizer.git
```

2. Move into the project folder

```bash
cd Smart-File-Organizer
```

3. Run the program

```bash
python main.py
```

## 📂 Output

The application automatically creates folders such as:

- Images
- PDFs
- Videos
- Audio
- Documents
- Others

and moves the corresponding files into their respective folders.

## 🎯 Use Cases

- Keep the Downloads folder organized
- Automatically separate media and documents
- Save time by avoiding manual file sorting
